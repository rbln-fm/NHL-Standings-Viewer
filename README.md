# NHL Table Viewer 🏒

## What is it?
An app that lets you view the **standings** and other related data of the **National Hockey League (NHL)**, run with **Python and Flask**.

## Is it working?
>**Why yes! *However...*** 

It is heavily a **work in progress** (as can be seen in the unstylized Home page and the unpolished Standings page). Be sure to keep a lookout, though!

## Why did you make this public, then?
>***Why not...?***

Mainly to add to **my portfolio** (a class requirement) [here](https://cmsc100-laboratory.github.io/02-my-github-page-rbln-fm-100/)!

## How do I run it?
**Run `pip install -r requirements.txt`** on your terminal, and then **run `python3 nhlapp.py`**.
